        Pengaturan

        Zona jarak dari kantor BNI

        Bawaan 1 / 5 / 10 km. Usaha di luar batas hijau tetap ditampilkan sebagai "Luar zona" sampai jangkauan maksimal (bawaan 20 km, maksimal 50 km). Jangkauan besar membuat deteksi lebih lama.

        Target plafond kredit

        Prospek dengan estimasi plafond di rentang ini diberi tanda "Sesuai target".

        Sumber deteksi PT/CV

        Gratis dari Google tiap bulan: 5.000 pencarian dan 1.000 detail (telepon/situs web). Batas aman menghentikan aplikasi sebelum kuota gratis terlewati; hitungannya hanya untuk perangkat ini.

        Deteksi

        Profil RM (pesan WhatsApp dan laporan)

        Diganti otomatis: {waktu} (pagi/siang/sore), {sapaan} (dari isian PIC), {nama_rm}, {jabatan}, {kantor}, {perusahaan}. Kirim satu per satu kepada calon debitur, jangan massal. Kantor dikosongkan berarti memakai kantor yang sedang aktif.

        Impor dari Excel

        Cara pakai

        Alur kerja

        1. Pilih kantor BNI: klik penanda di peta atau cari di tab Cabang. Gunakan Lokasi saya untuk melihat kantor terdekat. Kantor belum ada? Tekan Tambah kantor di tab Cabang. Data kantor salah? Pilih kantornya lalu Ubah data kantor.
        2. Aplikasi menggambar tiga zona dan mendeteksi PT, CV, UD, PD, Firma, dan koperasi di sekitarnya dari OpenStreetMap.
        3. Buka tab Peluang untuk melihat sektor usaha yang paling potensial, klaster usaha, pasar/mal/kawasan industri terdekat, dan bank lain di sekitar kantor.
        4. Buka satu perusahaan untuk melihat alamat, kontak, dan tautan riset (Google Maps, Street View, AHU, LinkedIn). Isi status, estimasi plafond, struktur organisasi, dan laporan keuangan; semuanya tersimpan otomatis ke Prospek saya.
        5. Tambahkan prospek yang belum ada di peta dengan tombol Prospek: ketuk lokasinya, atau tempel koordinat/tautan dari Google Maps. Daftar dari Excel juga bisa diimpor.
        6. Ekspor hasil deteksi atau pipeline Anda ke Excel untuk laporan.

        Kerja harian

        • Prospek → Agenda: follow-up terlambat, hari ini, dan 7 hari ke depan. Bisa dimasukkan ke Google Calendar atau diunduh sebagai .ics.
        • Prospek → Rute: sampai 10 prospek diurutkan menjadi rute terpendek, lalu dibuka di Google Maps. Isi otomatis dari prioritas teratas, dari detail perusahaan, atau dari klaster di tab Peluang.
        • Riwayat aktivitas di detail perusahaan: catat telepon, WhatsApp, dan kunjungan beserta langkah dan follow-up berikutnya. Status naik otomatis.
        • WhatsApp: isi Pengaturan → Profil RM sekali, lalu tombol WhatsApp di detail membuka chat dengan pesan perkenalan. Kirim satu per satu, jangan massal.
        • Kalkulator kelayakan: perkiraan KMK, KI, DSCR, dan plafond dari laporan keuangan. Ini perkiraan kasar, bukan analisis kredit resmi.
        • Prospek → Laporan: ringkasan mingguan atau bulanan untuk atasan, bisa disalin atau diunduh ke Excel.
        • Perusahaan yang sudah tutup atau bukan target bisa disembunyikan dari hasil deteksi lewat bagian bawah panel detail.

        Zona

        Saat sebuah kantor aktif, jarak dihitung dari kantor tersebut. Tanpa kantor aktif, jarak dihitung dari kantor BNI terdekat.

        Peluang pasar

        Rekomendasi disusun dari usaha yang terdeteksi di sekitar kantor. Bidang usaha ditebak dari nama dan kategorinya (mis. "distributor", "konstruksi"). Setiap sektor diberi skor: makin banyak usahanya, makin dekat ke kantor, dan makin cocok dengan kredit Rp1–25 miliar, makin tinggi skornya. Klaster adalah kumpulan minimal 4 usaha dalam radius 500 m. Pasar, mal, kawasan industri, pelabuhan, dan kantor bank lain diambil dari OpenStreetMap.

        Aplikasi tidak menyimpan data tren. Untuk melihat sektor yang sedang tumbuh, buka tautan PDRB dari BPS dan berita investasi di bagian bawah tab. Untuk jam ramai pasar atau mal, buka tautan Google Maps-nya. Isi "Bidang usaha" saat kunjungan agar tebakan sektor makin tepat.

        Dari mana datanya?

        • Kantor BNI dan badan usaha: OpenStreetMap (© kontributor OpenStreetMap, lisensi ODbL), diambil lewat Overpass API. Data ini diisi sukarelawan sehingga bisa belum lengkap atau kurang tepat, terutama untuk PT/CV kecil. Kantor BNI bisa ditimpa dengan daftar resmi melalui impor Excel.
        • Kantor BNI tambahan: Overture Maps Foundation (data tempat Meta, Microsoft, dan Foursquare; lisensi CDLA Permissive 2.0 dan Apache 2.0), sudah disaring tanpa ATM, agen, dan BNI Syariah. Penandanya bergaris tepi karena lokasinya bisa kurang tepat atau kantornya sudah tutup. Kantor yang sudah ada di OpenStreetMap tidak ditampilkan dua kali.
        • Struktur organisasi dan laporan keuangan tidak tersedia gratis untuk perusahaan tertutup. Sumber resminya AHU Online Kemenkum (berbayar per perusahaan) dan dokumen dari calon debitur sendiri. Hanya perusahaan Tbk yang laporan keuangannya publik (IDX). Isi data ini secara manual atau lewat impor.
        • Google Maps: tautan "Cari di Google Maps" di tab Deteksi membuka pencarian PT, CV, pabrik, dan lainnya di sekitar kantor, gratis tanpa API key. Perusahaan yang ditemukan di sana bisa dimasukkan sebagai prospek dengan menempel koordinat atau tautan tempatnya.
        • Pencarian alamat saat impor memakai OpenStreetMap Nominatim (maksimal 1 alamat per detik).

        Mode Google Maps

        Deteksi bisa memakai data Google Maps yang lebih lengkap. Anda perlu API key sendiri dari Google Cloud:

        1. Buka console.cloud.google.com, masuk dengan akun Google, lalu buat project baru (mis. "Peta Prospek").
        2. Buka Billing dan hubungkan akun penagihan (kartu kredit/debit). Google mewajibkan ini walaupun pemakaian Anda masih dalam kuota gratis.
        3. Buka APIs & Services → Library, lalu aktifkan tiga API: Maps JavaScript API, Places API (New), dan Map Tiles API.
        4. Buka APIs & Services → Credentials → Create credentials → API key, lalu salin key-nya (diawali "AIza").
        5. Klik key tersebut untuk membatasinya. Pada Application restrictions pilih Websites dan tambahkan alamat aplikasi, mis. https://emilianaaelgaa.github.io/*. Pada API restrictions pilih Restrict key dan centang tiga API tadi. Simpan.
        6. Disarankan: di Billing → Budgets & alerts buat anggaran kecil (mis. Rp50.000) agar Anda mendapat email bila ada tagihan.
        7. Di aplikasi ini buka Pengaturan → Sumber deteksi → Google Maps, tempel API key, lalu Simpan.

        Saat mode Google aktif, peta dasar berganti ke Google (aturan Google mewajibkan data Google tampil di peta Google). Setiap deteksi memakai paling banyak sejumlah pencarian yang Anda atur (bawaan 40); area terdekat dicari lebih dulu dan tombol "Cari lebih banyak" melanjutkan. Hasil Google tidak disimpan permanen dan tidak bisa diekspor; perusahaan yang Anda simpan ke Prospek saya tetap tersimpan beserta catatan Anda. Karena key dibatasi ke alamat situs, mode Google hanya berjalan dari alamat yang diizinkan (bukan dari file yang dibuka langsung di laptop).

        Privasi dan kepatuhan

        • Semua prospek, catatan, dan data pengurus tersimpan hanya di browser perangkat ini, tidak dikirim ke server mana pun. Unduh cadangan secara berkala di Pengaturan.
        • Jangan memasukkan data SLIK OJK. SLIK hanya boleh diakses untuk calon debitur yang sudah mengajukan kredit dengan persetujuannya, bukan untuk prospecting.
        • Nama pengurus dan pemegang saham termasuk data pribadi (UU 27/2022 tentang Pelindungan Data Pribadi). Simpan seperlunya dan ikuti kebijakan keamanan informasi BNI sebelum memakai aplikasi ini untuk data nasabah.
        • Aplikasi ini alat bantu pribadi, bukan aplikasi resmi BNI.
